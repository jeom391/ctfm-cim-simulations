# CTFM-CIM Simulations

Al-doped CTFM 소자의 R3 조건을 신경망 추론에 적용하고, 모델 구조와 ADC 조건에 따른 정확도 변화를 비교하기 위한 연구용 저장소입니다.

## 연구 질문

1. R3 측정값과 비이상성을 반영해도 신경망 추론 정확도가 유지되는가?
2. 같은 R3 조건에서 어떤 신경망 구조가 비이상성에 가장 강인한가?
3. 목표 정확도를 유지하는 최소 ADC 해상도는 몇 bit인가?

## 저장소 구조

```text
ctfm-cim-simulations/
├─ simulations/
│  ├─ 01-r3-inference/       # R3 조건 추론 정확도 및 반복 안정성
│  ├─ 02-model-robustness/   # MLP, CNN 등 모델별 강인성 비교
│  └─ 03-adc-sensitivity/    # ADC bit 및 레이어별 민감도 분석
├─ shared/                   # 공통 데이터 처리, 매핑, 평가 코드
├─ configs/                  # 공통/실험별 설정값
├─ data/                     # 로컬 데이터(원본 측정값은 Git에 올리지 않음)
├─ docs/                     # 실험 계획과 의사결정 기록
└─ tests/                    # 공통 코드와 실험 파이프라인 테스트
```

각 시뮬레이터는 순서대로 개발하되, 공통 기능은 검증된 뒤 `shared/`로 이동합니다.

## 시작 순서

1. R3 측정 데이터 스키마와 기준 디지털 모델을 확정합니다.
2. 시뮬레이션 1로 R3 기준선과 반복 실험 방식을 검증합니다.
3. 같은 입력·매핑·평가 규칙을 유지한 채 시뮬레이션 2를 진행합니다.
4. 선정된 R3 모델을 이어받아 시뮬레이션 3을 진행합니다.

자세한 범위와 산출물은 [실험 계획](docs/experiment-plan.md)을 참고하세요.

## 협업 규칙(초안)

- `main`은 실행 가능한 상태를 유지합니다.
- 작업 브랜치는 `feat/sim1-*`, `feat/sim2-*`, `feat/sim3-*`, `fix/*`, `docs/*` 형식을 사용합니다.
- 한 PR에는 하나의 실험 목적 또는 하나의 공통 기능만 담습니다.
- 실험 결과에는 설정 파일, seed, 코드 버전, 원본 데이터 버전을 함께 기록합니다.

- 라이선스 및 공개 범위
