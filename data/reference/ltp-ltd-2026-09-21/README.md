# 최신 LTP/LTD 공유 원본

사용자가 최종 지정한 `관련 자료/LTD,LTP`의 CSV 10개를 2026-09-21에 공유했다. 날짜는 공유일이지 측정일이 아니다. 원본 bytes를 그대로 복사했다. 이 자료는 과거 LTD/LTP 및 폐기된 260920 폴더를 대체한다. 파일 해시는 [manifest.json](manifest.json)에 있다.

## 적용

- A1~A5 각 LTP/LTD를 개별 조건으로 사용. A조건은 소자 개체 식별 번호와 같다고 가정하지 않는다.
- A=시간(s), B=Drain 전류(A), C=Gate 전압(V). 설명행/보조표를 값으로 읽지 않는다.
- A1/A2 헤더 2행, A3~A5 헤더 3행. 모두 데이터 12,000행, 기록 5.90005~7.09995초, 첫 쓰기 6.00005초.
- 기존 분석 시작 6초, 읽기 VGS=0V 허용오차0.05V, 쓰기 판정 abs(VGS)>=5V, 다음 쓰기 전환 j의 j-2 읽기 표본, VDS=0.1V 환산을 적용한다. VDS는 기존 공유 조건이며 CSV 세 열에서 직접 측정 확인한 값은 아니다.
- manifest 기대값은 독립적으로 primary table을 스캔한 참고값이다. 각 파일 511개 쓰기 구간/510개 채택 후보가 관측된다. 설정상 512회와 구분하며 후보 수를 장비의 명령 펄스 수로 해석하지 않는다.
- 마지막 read 구간은 다음 전환이 없어 기존 규칙대로 제외. 초기 상태는 6초 이전이므로 제외.
- `index.html/txt`는 파일 목록이므로 공유 대상에서 제외했다. 측정 CSV의 Remarks/보조표는 변경하지 않았다.
- 최종 raw hash와 분석 설정을 profile provenance에 저장한다. 이전 profile은 덮어쓰지 않고 새 revision을 발행한다.

## 개발 검증

이 버전의 실제 CSV 10개가 모두 parser→analysis를 통과해야 한다. 구판 A1의 특정 전류 11.5uA를 요구하지 말고 manifest의 해당 파일/행/전류로 검사한다. 파일별 개수 검증과 공통 j-2/단위 환산 검증을 분리한다.

초기 main fd27e4e 점검에서는 10개 중 9개가 실패했다. 후속 CSV 파서 수정으로 10개 모두 파싱·분석 검증을 통과했다. [수정 기록](../../../docs/csv-parser-fix-2026-09-21.md)을 참고한다. [마무리 계획](../../../docs/completion-plan-2026-09-21.md)을 따른다.

다른 측정 자료(IV/Retention/C2C), 팀 보고서, 실행 결과는 이번 공유에 포함되지 않았다. 이 폴더만 원본 Git 제외 규칙의 사용자 승인 예외이며 자료 전체를 무분별하게 추적하지 않는다. Git의 줄바꿈 변환을 막기 위해 이 폴더 CSV에 -text를 적용한다.
