# 팀 공유 원자료 스냅샷 — 2026-09-29

사용자 요청으로 연결된 로컬 저장소의 `관련 자료` 폴더 전체를 `files/`에 복사했다. 최신 전달 자료를 개발 담당자와 공유하기 위한 스냅샷이며 측정 조건·물리적 타당성을 승인한 데이터셋은 아니다.

## 구성과 사용

- CSV 10개, XLSX 77개, PPTX 4개, OPJU 1개, HTML 1개, TXT 1개: 총 94개, 22,029,837 bytes.
- LTP/LTD, IV Sweep, D2D, Retention, C2C, CCM 자료와 설명 자료를 원래 하위 경로·이름 그대로 보존했다. XLSX에는 원시 측정뿐 아니라 계산기·정리본도 포함된다.
- 바이트 수정, 단위 정정, 결측 제거, 열 교환, 소자 이름 변경을 하지 않았다. `manifest.json`에 각 파일 크기와 SHA-256이 있다.
- `LTD,LTP/A5/index.html` 및 `index.txt`는 장비 내보내기 색인이다. 분석 입력이 아니며 그 안의 외부 로컬 경로를 따라 파일을 가져오거나 측정 쌍으로 취급하지 않는다. OPJU/PPTX도 자동 CSV/XLSX 분석 대상이 아니다.
- IV Sweep과 D2D에 동일 파일이 있어도 원래 폴더별 의미를 보존했다. 중복을 서로 다른 물리 소자의 반복 측정으로 세지 않는다.
- 기존 `data/raw`와 로컬 `관련 자료`의 ignore 정책은 그대로 유지한다. 이번 공유는 이 스냅샷만 명시적으로 추적하는 예외다. 예전 문서의 '원자료를 올리지 않는다'보다 이번 사용자 업로드 요청이 우선한다.
- 추후 갱신은 새 날짜 스냅샷/manifest와 변경 이유를 추가한다. 실행 출처는 파일 해시로 기록해 기존 결과와 연결을 보존한다.

## C2C 적용 주의

[2026-09-29 C2C 점검](../../../docs/c2c-data-review-2026-09-29.md)을 먼저 읽는다. A1/A3/A5의 통계 계산 가능 여부와 시뮬레이션 적용 타당성은 별개다. A2/A4에는 미해결 형식·결측·해석 문제가 있다. 5 V·1 ms 합의와 ±10 V·10 ms 안내/주석의 차이는 소자팀 확인 중이다. 모든 파일에 합의 조건을 사실처럼 덮어쓰지 않는다.

## 검증

복사 당시 94개 모두 원본과 SHA-256 일치. 이 확인은 전송 무결성 확인이며 파서/웹/모델의 전체 실행 검증을 의미하지 않는다.
