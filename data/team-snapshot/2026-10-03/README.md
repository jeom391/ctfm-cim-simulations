# 팀 공유 원자료 보충 스냅샷 — 2026-10-03 (C2C만)

2026-10-02 스냅샷에는 C2C 파일이 A2 하나뿐이었다. 이후 소자팀이 A1·A3·A4·A5의 50-cycle C2C 파일을 추가했고, 로컬 `관련 자료/C2C/`의 5개 파일을 바이트 그대로 복사했다.

- `files/C2C/A1~A5_C2C_50Cycles.xlsx`: 원본과 SHA-256 일치(`manifest.json`). A2는 2026-10-02 스냅샷의 파일과 해시가 같다(변경 없음).
- 2026-10-02 스냅샷은 수정하지 않았다. 그 외 종류(LTP/LTD·D2D·Retention·IV)는 계속 2026-10-02 파일을 쓴다.
- 앱의 파일 인식은 C2C 파일에 스냅샷을 쓰지 않는다. 조건은 파일명 토큰(A1~A5), 형식은 `Id_sweeps` 시트에서 읽는다. 따라서 이 폴더는 화면 업로드 시 선택할 원본 위치다.
- 스윕 진폭: A1은 ±12 V(0→−12→+12→−12 V), A2~A5는 ±15 V.
- 알려진 데이터 특이점(수정·제외하지 않음): A4 사이클 3의 하강 중 0 V 값이 3.5e-13 A, A5 사이클 11의 상승 중 0 V 값이 1.848 µA(다른 사이클 약 16 µA), A5 사이클 11의 하강 끝부분(원본 행 499~502) 4칸이 비어 있음. 분석 대상 0 V 행(2, 202, 402)에는 모두 값이 있다.
- 측정 조건(VDS, 기록 절차)과 물리적 타당성을 승인한 데이터셋이 아니다.
