# C2C 추세 보정 분석 결정 및 근거

- 결정일: 2026-09-26
- 목적: 반복 기록에 따른 완만한 전류 변화와 그 주변의 편차를 분리한다.
- 상태: 분석 방법 결정. 파서·API·UI 구현 완료 또는 시뮬레이터 입력값 승인이라는 의미는 아니다.
- 근거: 사용자가 제공한 A3 엑셀의 직접 계산과 소자팀 답변. 3차식이 물리 법칙이라는 문헌 주장은 하지 않는다.

## 입력과 범위

로컬 원본: `관련 자료/C2C/_26CTFM_A3_1000Cycle_.xlsx`, 시트 `Origin_data`.
소자팀 전달 조건: Program +10 V·10 ms, Erase −10 V·10 ms, 각 Read 0 V, 1000 cycles.
Read 0 V의 단자 의미, VDS, 읽기 시간·추출 시점은 별도 메타데이터로 확인해야 한다. 기존 LTP/LTD의 조건을 자동 복사하지 않는다.

| 열 / 현재 범위 | 헤더 | 사용 |
|---|---|---|
| A2:A1001 | Cycle | 회차 n |
| B2:B1001 | Program_Id_uA | Program 읽기 전류, 독립 분석 |
| C2:C1001 | Erase_Id_uA | Erase 읽기 전류, 독립 분석 |
| D2:D1001 | Erase_minus_Program_uA | C−B 검산과 상태 차이 표시 전용 |

현재 파일은 회차 1~1000이 누락·중복 없이 존재하고 모든 값이 유한한 숫자다. D열은 C−B와 부동소수점 오차 범위에서 일치한다.
구현에서는 1000행을 하드코딩하지 않고 헤더로 열을 찾고 전체 데이터 행을 읽는다. 빈 후행은 제외하되 중간 결측, 중복 회차, 비숫자, 비유한 값은 조용히 삭제하지 않고 오류로 표시한다. 회차로 정렬하고 간격 누락도 확인한다.
원본을 수정하거나 초기 회차·이상치를 임의로 제외하지 않는다. D열의 편차를 개별 전도도 편차로 대체하거나 B·C를 하나로 합치지 않는다.

## 선택한 계산

Program과 Erase 각각 전체 유효 회차에 비가중 최소제곱 3차 다항식 피팅을 적용한다.

```text
x(n) = 2 × (n − n_min) / (n_max − n_min) − 1
T(n) = a + b×x(n) + c×x(n)^2 + d×x(n)^3
r(n) = I(n) − T(n)
z(n) = r(n) / T(n)
relative_residual_std_percent = 100 × std(z, ddof=1)
```

수치 계산은 QR/SVD 기반 최소제곱 등 안정적인 해법을 사용한다. 서로 다른 회차가 최소 5개 필요하며 이는 계산 가능 조건일 뿐 통계적 충분성을 보장하지 않는다. 모든 사용 지점의 T(n)이 양수인지 확인하고 아니면 상대 편차 출력을 막는다. 측정 범위 밖으로 곡선을 외삽하지 않는다.

출력은 **추세 보정 후 상대 편차**로 명명한다. 이는 잔차 표준편차를 잔차 평균으로 나눈 값이 아니다. 정의는 각 회차의 추세값으로 정규화한 잔차들의 표본 표준편차다. ddof=1은 기술 통계 정의이며 피팅 자유도와 자기상관까지 보정한 불편 잡음 추정량이라고 주장하지 않는다.

VDS가 모든 회차에 동일하고 0이 아니면 I와 G=I/VDS의 상대 잔차는 같으므로 이 통계는 µA 단위로 계산할 수 있다. 절대 전도도 산출에는 확인된 VDS가 별도로 필요하다.

## A3 계산 결과와 선택 근거

| 추세 모델 | Program 상대 잔차 표준편차(%) | Erase 상대 잔차 표준편차(%) |
|---|---:|---:|
| 1차 직선 | 0.685337 | 0.371592 |
| 2차 | 0.158631 | 0.074304 |
| 3차: 선택한 기본 분석 | 0.047767 | 0.051833 |
| 4차: 민감도 확인용 | 0.047234 | 0.042839 |

직선 제거 후 100회씩 나눈 잔차 평균은 초반·후반에 음수, 중간에 양수다. Program의 첫/중간(401~500)/마지막 구간 평균 잔차는 약 −1.036/+0.604/−0.703 µA다. Erase는 약 −0.625/+0.417/−0.479 µA다. 따라서 직선 하나로는 관측된 곡률을 제거하지 못한다.

3차식은 이번 A3에서 큰 곡률을 설명하면서 매 회차를 따라가는 고차 피팅을 피하기 위한 공학적 선택이다. 잔차가 작아진다는 이유만으로 최적·정답 모델이라고 판단하지 않는다. 모든 소자의 물리적 열화식이나 모든 향후 데이터에 검증된 보편 모델은 아니다.

중요한 제한: 3차에서 4차로 바꾸면 Erase 추정치는 약 17% 작아진다. 3차 잔차의 lag-1 상관도 Program 약 0.615, Erase 약 0.745로 남아 있다. 따라서 모델 의존성과 회차 간 연관성이 존재하며, 독립·동일분포인 순수 C2C 잡음을 분리했다고 볼 수 없다. 4차는 비교용이지 편차를 작게 만들기 위해 자동 채택하는 대안이 아니다.

## 해석과 시뮬레이터 경계

소자팀은 상태 차이 감소를 반복 P/E에 따른 열화로 설명했고, 두 전류의 동반 상승은 Program이 충분하지 않을 가능성으로 해석했다. 후자는 가설이다. 피팅 추세 전체를 확정된 열화 기전으로 명명하지 않는다. 잔차에는 읽기 잡음, 남은 추세와 모델 오차 등이 포함될 수 있다.

- 원본의 전체 표준편차와 추세를 보존한다. 전체 표준편차에서 다른 표준편차를 직접 빼지 않는다.
- Program·Erase별 결과를 따로 저장한다. 양의/음의 가중치 또는 G+/G− 경로와 P/E 명칭을 자동 대응시키지 않는다.
- 사용자 확정(2026-09-26): 시뮬레이터로 전달하는 대표 상대 편차는 **Program 결과만**이다. Erase는 초기화 재현성 및 반복 변화의 분석·진단용으로 유지하며 시뮬레이터에 추가로 적용하거나 Program과 평균하지 않는다. LTD 상태에 Erase CV를 자동 적용하지 않는다. Program 대표 CV를 두 물리 경로에 사용하되 경로별 난수 표본은 기존 계약대로 독립이다.
- 기존 LTP/LTD의 1 ms 조건 및 중간 전도도 상태 전체에 이번 ±10 V·10 ms 끝 상태의 편차를 적용하는 것은 근사 가정이다.
- 시뮬레이터에 적용한다면 사용자 확인을 거친 추정 시나리오로 제공한다. 이 문서의 수치를 검증된 소자 고유 상수로 자동 주입하지 않는다.
- 독립 무작위 인자로 샘플링하면 실제 잔차의 시간 상관은 재현하지 않는다. 이를 명시한다.
- 반복 횟수에 따른 열화 시뮬레이션은 별도 확장이다. 이번 결정으로 Retention 시간 변화 또는 내구성 모델을 구현한 것으로 간주하지 않는다.
- 이전의 C2C 미제공 문구에 대해 A3 자료 수신 및 분석 결정을 추가하는 문서다. 기존 스키마·엔진 계약은 별도 변경 작업에서 갱신한다.
