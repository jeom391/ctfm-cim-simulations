# LTP/LTD 공통 창 제안 검토

검토일: 2026-09-18. 대상: 사용자가 제공한 공통 창/상태 분할 제안 이미지. 문헌 검토와 주 작업자의 로컬 데이터 검증 결과를 합쳤으며 구현 변경은 하지 않았다.

## 결론

공통 창은 **양쪽 기록 경로에서 도달 가능한 후보 범위만 사용한다는 보수적 실험 조건**으로 타당하다. 그러나 사전학습 가중치를 매핑한 뒤 추론하는 현재 프로젝트에서 반드시 요구되는 규칙은 아니다. 공통 범위가 있다는 것만으로 같은 목표값에 두 방향 모두 정수 펄스로 도달하거나, 그 상태에서 방향을 바꾸어 임의의 다음 상태로 이동하거나, 반복 기록이 재현된다는 것이 입증되지는 않는다.

디지털 학습 후 추론과 소자 내 양방향 가중치 업데이트 학습은 요구조건이 다르다. 원 논문은 이를 구분하며, 비대칭 스위칭이 특히 직접적인 소자 내 SGD 업데이트를 어렵게 한다고 설명한다. 따라서 추론 전용 시스템에 양방향 학습의 조건을 자동으로 강제해서는 안 된다. [Rasch et al., 2024](https://www.nature.com/articles/s41467-024-51221-z)

## 이미지 제안에서 수정할 부분

- A1/A2의 교집합 부재는 **현재 공통 창 방식으로 평가할 수 없음**을 뜻한다. 단일 방향 초기화 후 기록하는 추론 시나리오까지 불가능하다는 결론이나 공정 불량의 원인 판정은 이 자료만으로 할 수 없다. 소자팀의 별도 공정 판단과 범위 계산에서 얻은 결론을 구분한다.
- 5점 평균은 서로 다른 펄스 상태를 섞은 추정값이다. 누적 최대/최소는 각각 위/아래 방향의 편향과 평탄 구간을 만들 수 있다. 원본과 전처리 곡선을 모두 보존하고 전처리를 거친 값을 실측 단일 상태로 표시하지 않는다. 반복 측정 없이 1σ=0.2 µS를 C2C나 일반적인 읽기 잡음으로 확정하지 않는다.
- G 등간격 표는 **목표 상태 표**로 사용할 수 있다. 보간된 1.7회/16.4회는 추정한 연속 펄스 좌표이며 고정 폭 펄스의 실제 실행 횟수가 아니다. 정수 펄스 번호의 실측 G를 선택해 목표와의 오차를 남기거나, 별도 검증된 write-verify/가변 펄스 프로토콜을 가정해야 한다.
- 동일 state_id에는 공통 목표 G를 둘 수 있지만, 실제 LTP/LTD 도달값, 정수 펄스 수, 목표 대비 오차, 출발 초기화 조건을 각각 저장해야 한다. 허용오차 내에서만 같은 목표 상태로 채택한다.
- 등간격이 최종 신경망 정확도 손실을 최소화한다는 보장은 없다. 상태 수·가중치 분포·스케일·잡음에 따라 결과가 달라지므로 평가할 설계 선택이다.
- `1펄스 도달 가능 최대 N = 12/10/15`는 산정식, 허용오차, 정수 펄스 적용 방식, 상태/구간 수 구분이 없어 검증되지 않았다. 상태 간격이 크다는 사실만으로 목표에 한 펄스 만에 정확히 도달하는 것은 아니다.
- alpha 피팅 값은 곡선 모델·식·정규화·적합 구간과 함께 기록한다. 추론에 실측 상태를 직접 사용하는 경우 alpha를 추가 오차로 또 적용하면 동일 비선형성의 중복 반영이 될 수 있다.

## 근거와 도구 연결

주 작업자가 현재 추출 규칙으로 확인한 원본 범위와 이미지의 공통 창은 아래와 같다(µS). 이미지에 적힌 원본 시작/끝 값으로도 아래 원본 교집합에 가까운 값이 나오므로, 제시된 목표 경계에는 명시되지 않은 처리 또는 여유폭이 있다.

| 프로필 | 원본 교집합 | 이미지 공통 창 |
|---|---:|---:|
| A1 | 없음 | 없음 |
| A2 | 없음 | 없음 |
| A3 | 174–408 | 183–389 |
| A4 | 240–441 | 251–421 |
| A5 | 317–588 | 326–586 |

5점 이동평균의 끝점 처리/트리밍과 이후 단조화에 따라 범위가 달라진다. 이 차이를 계산 오류로 단정할 수는 없으며 원 계산 스크립트나 경계 선택 규칙이 필요하다.

AIHWKit `CustomPairConductanceConverter`는 `g_lst`를 이산 도달 상태 제약으로 해석하는 것이 아니라 `numpy.interp`를 이용한 g(w) 함수 보간에 사용한다. 실측 유한 상태만 사용하려면 별도의 상태 선택/양자화 단계가 필요하다. 이는 AIHWKit의 기능 설명이지 실물 도달 가능성의 증명이 아니다. [공식 구현](https://aihwkit.readthedocs.io/en/latest/_modules/aihwkit/inference/converter/conductance.html)

실제 아날로그 메모리 연구는 원하는 목표 전도도와 실제 기록값을 구분하며 write-and-verify로 허용오차를 달성한다. 따라서 보간한 목표값을 검증 없이 실제 기록값으로 취급해서는 안 된다. 이 원리는 PCM/ECRAM 연구에서 확인되는 프로그래밍의 구분이며, 해당 재료의 수치나 동작 모델을 현재 CTF 소자에 그대로 적용한다는 뜻은 아니다. [원 연구: Open-loop analog programmable electrochemical memory array](https://www.nature.com/articles/s41467-023-41958-4), [원 연구: Optimised weight programming](https://www.nature.com/articles/s41467-022-31405-1)

원 연구 두 건의 웹 전문 열기는 제공자 오류로 실패했으며, 검색 결과에 노출된 원 논문의 설명만 이용했다. AIHWKit 구현 및 Rasch et al. 원문은 직접 열어 확인했다.

## 권장 평가 구분

1. 실측 풀 기반 추론: 방향과 초기화 경로를 보존한 정수 펄스 실측값만 매핑한다.
2. 공통 창 기반 추론: 양방향 후보 범위로 제한하고, 각 목표에 대응하는 실제 방향별 오차를 남긴다. A1/A2는 이 조건에서만 N/A다.
3. 등간격 이상 목표 대조군: 보간된 가상 목표를 사용한다면 가정 실험으로 별도 표시한다.

공통 창 방식 채택은 가능하지만, 그림 전체를 검증된 실측 상태 생성 절차로 승인하는 것은 권하지 않는다.
