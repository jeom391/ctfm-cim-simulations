# 구현 진단 후속 설명과 C2C 확장 제안

2026-09-21 · 코드 확인 기준 fd27e4e. 진단/제안 문서이며 새 기능 구현 완료 또는 C2C 계약 확정이 아니다.

## 측정 입력과 실제 검증

현재 사용자가 최종 정리한 로컬 `관련 자료/LTD,LTP` CSV 10개가 분석 대상이다. 이전 260920 및 구판은 폐기됐다. 공개 저장소에 원본은 포함되지 않으므로 개발 담당에게 별도 전달한다. 파일 해시/버전으로 어떤 자료를 검증했는지 기록한다.

최신 코드의 parse_table을 실제 파일에 적용하면 A1 LTD만 읽히며 9개는 실패한다. A1 LTP/A2는 뒤의 보조 표를 측정 테이블로 읽고, A3~A5는 Remarks 행을 헤더로 오인한다. 메모리에서 해당 메타데이터/보조 표를 분리하면 확인한 사례가 통과했다. 원본을 다시 측정할 이유는 없다. 명시적인 헤더/데이터 구간 선택을 지원하고, 알려진 장비 형식 자동 인식은 사용자 미리보기와 확인을 제공한다. 데이터 블록 내부의 잘못된 값은 조용히 버리지 않는다. 원본 row와 hash를 유지한다.

이는 측정 분석 입구의 문제이므로 시뮬레이터에만 속한 결함이 아니다. core 계산 합성 테스트 통과와 최신 원본 전체 분석/프로필 발행/추론 성공은 구분한다. A1 LTD 검증은 현재 원본에 없는 과거 11.5uA를 고정 기대하여 실패했다. 공통 계산 규칙 검증과 파일별 골든 값 검증을 분리한다.

## 조건부 PPA 근거와 실행 연결

기존 [08 명세](spec/08-hardware-baseline.md)와 [근거 문서](research/hardware-baseline-evidence.md)의 방향을 유지한다. 2026-09-21 원문 재확인:

- [Lu 등, NeuroSim Validation and Benchmark, 2021](https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2021.659060/full): 특정 RRAM macro의 회로 모델/보정 검증. 이 결과가 CTFM 등가 회로 전체를 검증하지는 않는다.
- [Charge-trap synaptic device…, 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11585655/): CTF 측정 특성과 NeuroSim 사용 사례, 64×64/5bit/8열 공유를 비교 기준으로 참고. 우리 소자 최적값의 증거는 아니다.
- [NeuroSim V1.5, 2025 preprint §II-C](https://arxiv.org/html/2505.02314v1): 입력 표현과 bitserial PPA 경로의 구분. 현재 V1.4와 정확히 같은 기능이라고 확대 해석하지 않는다.

22nm/300K, 등가 셀 footprint, 0.55V/10ns 및 선형 전도도 전이는 설계 가정이다. 실측값 또는 CTFM 보정 완료라 부르지 않는다. 가정 표시만으로 완성되지 않으며 G pair/bit trace/ADC 순서/물리 구성 대응이 필요하다. 미모델링 블록은 누락 표시하고 전체 비용은 null로 둔다.

현재 schema는 PPA=off만 허용하며 실행기가 preset을 전달하지 않는다. 이 상태와 별도 엔진 smoke-test 성공을 혼동하지 않는다. assumed_proxy 설정 등록→검사→실행 연결과 블록 계측은 개발 작업이다.

## 입력 불일치의 의미

파일 확장자 문제가 아니라 계산 의미의 불일치다: 실제 비균일 G+/G−와 균일 복원 weight, unsigned256단계와 signed 비음수128단계, 256개 trace와 첫 이미지1개. 정확도 기준을 보존하고 NeuroSim adapter를 맞추는 것이 권고다. 정확도 쪽을 편의상 signed/균일 상태로 바꾸면 기존 정확도 실험 자체가 달라진다. 대체 근사를 쓰면 별도 결과로 명시한다.

## C2C 현재 상태와 확장 제안

확인: UI는 미제공 안내만, payload c2c=false/n_reprogram=1, schema가 고정, core가 활성화를 거부, effect_owners.c2c=null. 수동 표준편차 입력 및 적용 계산은 미구현이다.

측정 파일 parser를 기다리지 않고 수동 가정 기반 C2C 모듈을 구현하는 것은 가능하다. 기존 설계의 의도적인 비활성화에서 범위를 확장하는 작업이다. 아래는 후속 합의·명세 대상이다.

- 수동 입력은 `상대 기록 편차 CV(%)`를 권고한다. 무단위 표준편차라는 모호한 이름을 사용하지 않는다. 절대 sigma_G[S/uS]를 받는다면 단위/적용 기준 상태를 명시해야 한다.
- 실측 sigma_I를 CV로 변환하려면 평균 I가 필요하다. CV=sigma_I/mean_I; 고정 VDS에서 전류/전도도 CV는 같다. 평균은 기준 가중치를 교체하기 위한 값이 아니라 정규화의 기준이다.
- 원자료 없이 수동 입력한 값은 사용자 가정으로 표시하고 실측 profile 값을 덮어쓰지 않는다. 상태 하나에서 얻은 CV를 모든 상태에 적용하는 것은 별도 가정이다.
- D2D는 같은 배열에서 고정. C2C는 재기록마다 셀/plane별로 생성하고 한 번 기록한 뒤 모든 시험 이미지에서 고정한다. 읽기마다 새로 뽑는 read noise와 구분한다. 같은 재기록 표본으로 시간/ADC 비교한다.
- 평균1의 양수 배율 분포(예: lognormal)는 음의 G를 피하는 모델 후보일 뿐 실측 분포로 단정하지 않는다. 분포/상관/범위 초과 처리/반복수/seed와 식을 구현 전에 확정한다. clipping은 편차를 바꾸므로 조용히 적용하지 않는다.
- 측정 보조의 평균/표본 std/CV 계산 자체도 원자료 형식을 몰라도 합성 회차별 입력으로 구현 가능하다. 남는 것은 장비 파일 추출과 실제 조건/정상성 검증이다.

## 오류 문서 정정

개발 담당 보고: MNIST가 subarray256에서는 완주하고64/128에서는 crash. 따라서 모든 MNIST/작은 출력이 실행 불가라는 이전 일반화는 철회한다. 이 문서 작성에서 Linux engine을 재실행한 것은 아니다. 256으로 사용자 요청을 몰래 바꾸지 않는다.
