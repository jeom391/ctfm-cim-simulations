# 추가 측정 없이 가능한 비교와 해석 범위

작성: 2026-09-17. 기존 자료로 연구 질문을 유지하기 위한 검토이며, 아래 설계 제안은 소자의 새로운 실측 특성이 아니다.

## 결론

후속 설명 반영: 현재 1 ms/1 ms 측정은 최대 펄스 수 제한으로 수렴에 도달하지 않았을 수 있다. 본 문서의 G 범위는 **현재 측정 경로의 관측 범위**이며, 포화 범위나 소자의 절대 가용 범위가 아니다. 현재 상태 풀의 수치 진단은 유지되지만, 추가 펄스·다른 간격에서 얻을 범위와 상태 수를 현재 종단 값만으로 확정하거나 외삽하지 않는다.

현재 LTP/LTD의 상태 목록을 버리거나 Memory window에 비례해 범위를 임의 확장할 이유는 없다. 현재 펄스 조건에서의 관측 상태와 그 상태를 사용하는 매핑을 비교할 수 있다. 추가 펄스 조건의 최적 성능이나 반복 기록 가능성을 입증하는 것은 별개이다.

## 근거와 제안

### 전도도 범위가 좁으면 반드시 정확도가 나쁜가?

아날로그 가중치는 단위 없는 소프트웨어 가중치를 전도도 차이와 scale로 변환한다. 같은 가중치도 여러 전도도 조합으로 구현할 수 있고, 구현 방식에 따라 오차가 달라진다. [Mackin et al., Nature Communications (2022), Fig. 1 및 Eq. 2](https://www.nature.com/articles/s41467-022-31405-1)

수학적 설계 추론: G 범위와 scale을 함께 바꾸면 좁은 절대 범위도 같은 정규화 가중치 범위를 표현한다. 매핑만 비교할 때 중요한 것은 정규화 상태 간격, 빈 구간, 타깃 가중치 분포이다. 실제 잡음이 포함되면 차동 신호가 작은 조합의 오차가 커질 수 있고, 큰 공통 전도도는 전류·회로 부담과 연결될 수 있다. 그러므로 범위가 넓다는 이유만으로 우수하거나 좁다는 이유만으로 실패한다고 판단하지 않는다.

기존 최저 전도도 고정 방식과, 측정된 두 상태를 선택하는 일반 차동쌍 방식을 비교할 수 있다. 후자는 새 단일 소자 상태를 만드는 것이 아니라 관측된 G_i−G_j를 사용하는 것이다. 다만 두 소자를 각 상태로 독립 기록할 수 있다는 가정, 동률 시 낮은 공통 전도도를 우선하는 규칙, 잡음 민감도 평가가 필요하다. 실제 정확도는 추론 전까지 확정할 수 없다.

### Memory window로 가상의 전도도 범위를 만들 수 있는가?

CTF 기반 단일 트랜지스터 시냅스의 원논문은 전하 포획에 따른 Vth 이동, Id–Vg 전이 특성 및 전도도 상태를 연결해 설명한다. 같은 읽기 전압에서 문턱전압 이동에 따라 채널 전도도가 바뀐다. [Han et al., Science Advances (2021), Fig. 2D–F](https://pmc.ncbi.nlm.nih.gov/articles/PMC8336957/)

설계 추론: Memory window는 두 문턱전압의 차이이며, 그것만으로 읽기 전류의 극값이나 중간 상태 분포가 결정되지는 않는다. Vth의 절대 위치와 transfer curve의 형태, 읽기 VGS·VDS가 필요하다. MW를 곱셈 계수로 써서 LTP/LTD 범위를 늘리는 방식은 현재 자료로 정당화되지 않는다.

가능한 후속 모델은 실측 transfer curve를 보정한 Vth 이동 모델이다. 곡선들이 수평 이동만으로 설명되는지 먼저 검증해야 하며, 맞지 않으면 단순 이동 모델을 쓰지 않는다. 모델로 만든 중간 상태는 관측 상태와 분리한다. IV sweep의 여러 전압점 자체를 가중치 상태 목록으로 취급하면 읽기 조건의 변화와 저장 상태 변화가 섞이므로 부적절하다. 같은 읽기 전압에서 sweep별 전류를 비교하더라도 펄스 기록 상태와 동일하다고 단정하지 않는다.

### 현재 데이터로 유지할 수 있는 실험

1. A1~A5별 실측 LTP만, LTD만, 통합 후보를 비교한다. 동일한 모델·입력·매핑 최적화 예산을 사용한다.
2. 전도도 범위, Gmax/Gmin, 정규화 최대 간격, 타깃 가중치 양자화 오차를 함께 표시한다. 측정 표본 수를 반복 기록 가능한 유효 상태 수로 부르지 않는다.
3. 측정 MW와 위 지표를 나란히 비교하되, A1~A5에서 기대했던 상충관계가 실제로 나타나는지 확인한다. 사전에 순위를 강제하지 않는다.
4. 별도 대조군으로 같은 실측 Gmin/Gmax와 명시한 상태 수를 가진 균등 상태 목록을 사용할 수 있다. 이름은 '가상 균등 상태 대조군'이며, 실측 상태나 다른 펄스 간격의 예측값으로 보고하지 않는다. 최적 성능의 보장된 상한도 아니다.
5. 추가 측정 없이 실제 상태로 가능한 매핑·scale·클리핑 조정부터 평가한다. 매핑 최적화에는 검증 세트를 쓰고 최종 테스트 세트로 설정을 고르지 않는다.

## 현재 파일의 수치 진단

동일 작업에서 수행한 CSV 계산 결과를 아래에 기록한다. 시간 6초 이상에서 다음 펄스의 `|Vg| > 5 V` 전환 행 j를 찾고 j−2행의 전류를 0.1 V로 나누었다. 각 파일에서 다음 전환으로 판별 가능한 내부 표본 510개를 추출했다. 마지막 펄스의 포함 규칙이나 반복 기록 오차는 이 계산으로 검증하지 않았다.

|---|---:|---:|---:|
| A1 | 11.4–495 | 48.18% | 17.783% |
| A2 | 57.7–234 | 35.73% | 0.567% |
| A3 | 157–544 | 0.78% | 0.258% |
| A4 | 147–529 | 1.05% | 0.262% |
| A5 | 271–605 | 5.09% | 0.299% |

세 번째 열은 관측된 단일 소자 전도도 후보를 정렬한 지표이며, 네 번째 열은 관측값 사이의 모든 `|Gi−Gj|`를 정렬한 지표이다. 두 지표는 동일한 전체 전도도 범위로 나눈 값이다. 이는 실제 모델 정확도가 아니라 이상적인 수치 표현 간격의 진단이다.

이 결과는 모든 프로필에서 큰 빈 구간이 생기는 것은 아니며, 한쪽을 Gmin에 고정하는 매핑보다 두 상태를 선택하는 차동 매핑으로 간격을 줄일 가능성이 있음을 보여준다. 특히 A2는 전도도 범위가 비교적 좁지만 차동 후보 간격이 작다. A1은 모든 쌍을 허용해도 큰 간격이 남으므로 방향별 풀과 scale 조정도 비교할 필요가 있다.

CSV 숫자의 정밀도를 서로 구분되고 재현 가능한 물리 상태 수로 해석하면 안 된다. 위 수치는 잡음, 독립 재기록, 소자별 편차를 포함하지 않으며, 작은 차이를 큰 두 전류의 차로 구현할 때 생기는 오차와 공통 전류 비용도 포함하지 않는다. 방향별/통합 풀과 Gmin 고정/일반 쌍 탐색을 동일한 검증 조건에서 비교하는 것이 적절하다. 모델의 추론 정확도는 본 검토에서 계산하지 않았다.
