# 실험 계획

## 공통 원칙

- 모든 비교는 동일한 R3 측정값, conductance 매핑 규칙, 데이터셋 분할, seed 정책을 사용한다.
- 절대 성능을 과도하게 해석하지 않고, 동일 조건에서의 상대적 경향을 우선 보고한다.
- 원본 측정 데이터는 변경하지 않으며, 전처리 결과와 생성 데이터는 재현 가능한 코드로 만든다.
- 각 실행은 설정, seed, Git 커밋, 데이터 버전, 주요 지표를 함께 남긴다.

## 1. R3 조건 추론 정확도

### 목적

R3의 Gmin/Gmax 및 variation을 가중치에 반영했을 때 MNIST 추론 정확도와 반복 안정성을 측정한다.

### 입력

- 기준 디지털 모델과 가중치
- R3 conductance 측정값 또는 요약 통계
- 가중치-conductance 매핑 규칙
- 반복 횟수와 seed 목록

### 출력

- 디지털 기준 정확도
- R3 조건 평균 정확도와 표준편차
- 디지털 기준 대비 정확도 유지율
- 반복 실행별 원시 지표

### 완료 기준

- 하나의 명령으로 동일 결과를 재현할 수 있다.
- 설정과 seed가 결과 파일에 기록된다.
- 이상적 조건과 R3 조건의 차이를 자동 검증하는 테스트가 있다.

## 2. 모델 강인성 비교

### 목적

동일한 R3 조건에서 MLP, CNN 등 후보 모델의 비이상성 강인성과 매핑 비용을 비교한다.

### 비교 기준

- 디지털 학습 정확도 대비 유지율
- variation 증가에 따른 정확도 하락 폭
- 필요한 타일 수 등 매핑 비용
- 레이어별 민감도

### 완료 기준

- 모든 모델이 동일한 공통 평가 파이프라인을 사용한다.
- 모델별 하이퍼파라미터와 체크포인트 출처가 기록된다.
- 정확도와 매핑 비용을 한 결과 표로 비교할 수 있다.

## 3. ADC 민감도 분석

### 목적

시뮬레이션 2에서 선정한 모델을 기준으로 ADC 해상도와 레이어별 민감도를 평가한다.

### 실험 축

- ADC: 3~8 bit
- 전체 레이어 동일 bit
- 레이어별 bit 감소
- ADC 포화율과 양자화 오차

### 출력

- ADC bit별 정확도 곡선
- 소자 손실과 ADC 손실의 분리
- 목표 정확도 손실 이내의 최소 bit
- 정밀도에 민감한 레이어 순위

### 완료 기준

- ADC 외 조건이 고정되었음을 설정으로 검증한다.
- bit별 반복 실험과 신뢰구간을 산출한다.
- 최소 ADC 요구조건의 산출 규칙이 문서화되어 있다.
