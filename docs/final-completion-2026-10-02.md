## 2. 적용 수식

### C2C (A2_C2C_50Cycles.xlsx, SHA-256 `49959edc…52d9`)

같은 구간의 전류 I_n (n = 1…50), 단위 A. 0 V 지점은 `Sweep_segment` 라벨의 연속 구간과 Vg의 증감으로 식별하며, 구간당 Vg = 0이 정확히 하나가 아니면 계산하지 않고 사유를 남긴다. 최초 0 V는 첫 구간의 첫 행만 쓴다.

```text
전체 변동      CV = 100 * SD(I, N-1) / |mean(I)|          (mean = 0 이면 계산 불가)
추세 제거 후   T_n = a + b*n (OLS, n = 1..N)
               e_n = (I_n - T_n) / T_n                     (모든 T_n이 유한·양수일 때만)
               CV = 100 * SD(e, N-1)
```

결측·비수치 셀은 해당 구간 전체를 계산하지 않고 셀 위치를 기록한다(다른 구간은 계산). 음수 값은 절댓값 처리하지 않는다. N−1은 계산된 상대 잔차의 표본 SD 정의이며, 회귀 잔차 SD `sqrt(Σr²/(N−p))/mean`과 다른 값이다.

### D2D

```text
조건 k (진폭, 분기)마다   G = Id(Vg = 0 V) / 0.1 V        (구간 내 정확한 0 V 표본 또는 인접 두 점 선형 보간)
                          CV_k = SD(G1, G2; N-1) / mean(G1, G2) = |G1-G2| / sqrt(2) / mean
대표값                    CV_D2D = sqrt(Σ CV_k² / K)
```

Erase는 상승 구간, Program은 상승 구간 바로 뒤의 하강 구간(+A → −A 전체)이다. 0 → −A 초기 반구간은 Program으로 쓰지 않는다.

### Retention 외삽

실측 적합 `I(t) = a + b·log10(t / 1 s)` (t ≥ 10 s, OLS, 기존 구현)를 측정 종료부터 10년(3.15576e8 s)까지 평가한다. 0 도달 시점 `10^(−a/b)` (b < 0), Program·Erase 적합선 교차 `10^((a_E − a_P)/(b_P − b_E))`는 측정 종료 이후일 때만 표시한다. 로그 공간에서 비교하므로 기울기가 0에 가까운 경우에도 overflow 없이 "해당 없음"이 된다.

### 시뮬레이터 적용 (기존 구현 유지)

`c = CV/100`, `tau = sqrt(log1p(c²))`, `F = exp(−tau²/2 + tau·Z)`. D2D는 배열별 고정, C2C는 재기록마다 새 배율이며 두 전도도 plane에 곱한다.

## 5. 프론트·흐름 검증 (실제 브라우저, Chrome)

직접 확인한 항목(WSL 서버 + Windows Chrome, 실제 파일 입력에 스냅샷 파일 주입):

```sh
# 한 번만: 엔진 환경 (scripts/linux/README.md)

# 웹 빌드 (Windows 또는 Linux)
cd apps/web && npm ci && npm run build && cd ../..
# 실행 / 상태 / 종료 (WSL)
bash scripts/linux/serve.sh start     # http://127.0.0.1:8000

```

## 8. 연구 가정 (구현 결함 아님)

- 대표 C2C 값 하나를 프로필의 모든 LTM 상태에 공통 적용, 로그정규 배율 — 공학적 가정.
- 전체 변동은 사이클 추세를 포함하고, 추세 제거 값은 선형 모델·정규화에 의존한다. 두 값으로 별도 실행해 차이를 비교한다(#2, #3).
- D2D는 선택한 물리 소자 2개 기준이며 조건별 CV의 RMS 집계는 기존 구현의 가정이다.
- Retention 10년 값·교차 시점은 로그-선형 모델 외삽이다.
