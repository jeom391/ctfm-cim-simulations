# 측정 결과 화면 개선 — 2026-09-21

남은 작업 중 로컬에서 가능한 측정 결과 화면의 대형 JSON 렌더링 문제를 처리했다.

## 변경

- 계산 요약은 항목/값 표, 전도도 풀은 가용 여부·후보 수·Gmin/Gmax 표로 표시한다. state_ids 배열 전체를 요약 화면에 출력하지 않는다.
- raw/states/제외 기록/설정·출처 상세는 펼칠 때만 생성한다. 표는 50행씩 이전/다음으로 교체하며 행을 계속 누적하지 않는다.
- 긴 문자열과 중첩 배열은 화면에서 축약하며 전체 원본은 기존 다운로드 파일로 제공한다.
- 제외 사유는 사유별 기록 건수와 상세 표로 구분한다. 기록 수와 제외 측정 행 수는 다름을 표시한다.
- 프로필 상태 선택표도 50행씩 표시한다. 선택값은 부모에서 관리하여 페이지를 이동해도 유지된다.
- 서버 계산·원본·프로필 계약은 변경하지 않았다.

## 검증

- 웹 테스트 15/15 통과: 기존 13개, 상태 ID 1,020개 중첩 출력 방지와 원본 보존, raw 24,000행의 누락 없는 페이지 이동 2개 추가.
- TypeScript 검사 및 Vite production build 성공. Node 24.19.0 사용.
- 실행 중인 로컬 API/worker에서 measured_workflow.py --conditions A3 --experiment-conditions "" 완료. 후보 1,020개, 프로필 발행·ZIP 다운로드 성공. MNIST는 실행하지 않음.
- 로컬 분석 ID: 13f94a6e-b75b-432c-8fea-939906a43047. 공유 가능한 원본은 data/reference/ltp-ltd-2026-09-21이며 runtime 결과는 Git에 포함하지 않는다.
- 브라우저: 요약에 후보 1,020개와 풀별 범위, raw 24,000행 및 states 1,020행의 접힌 상세 표 확인. states 1→2페이지 이동 확인.
- 브라우저: 프로필 후보 체크 후 1→2→1페이지 이동 시 선택 1개와 체크 유지 확인.

## 한계·후속

이번 완료 범위는 렌더링·표시 개선이다. API가 전체 결과를 내려받는 방식과 전송 크기는 그대로다. 서버 측 pagination/요약 전용 API, 검색, 다른 화면의 공통 JSON 컴포넌트 변경은 추가하지 않았다. 성능 개선 배수를 측정한 것은 아니다.
