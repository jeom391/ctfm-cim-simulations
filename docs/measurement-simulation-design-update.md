## 최신 소자팀 답변에 따른 정정

아래 내용은 후속 대화에서 전달된 소자팀 답변으로, 본문 이전 기록과 충돌하면 우선한다.

- **LTP/LTD 수렴 여부:** 후속 설명에 따르면 최대 펄스 수 제한이 있고, 현재 1 ms/1 ms 조건은 수렴까지 도달하지 않았을 수 있다. 종단 값이나 후반부의 작은 변화를 포화의 증거로 단정하지 않는다. Gmin/Gmax는 채택한 실측 상태 풀의 관측 범위로 정의하며 소자의 물리적 한계로 표현하지 않는다. 다른 간격에서의 수렴 및 도달 범위는 해당 비교 자료 없이 추정해 채우지 않는다.

- **C2C:** 자료가 없는 것으로 알고 있으나 지혜의 확인이 남아 있다. ‘없음 확정’이 아닌 ‘미확인·현재 미제공’으로 기록한다.
- **IV Sweep VDS:** 0.1 V로 확인됐다. 소자팀은 1~15 V의 각 sweep 진폭별로 전류와 memory window를 비교하기를 원한다. 전류의 ‘최댓값...?’은 제안 표현이므로 최종 D2D 대표 통계 정의로 확정하지 않는다.
- **Vth branch:** Erase는 −15 V → +15 V의 증가 방향 전체, Program은 +15 V → −15 V의 감소 방향 전체를 사용한다. 기존 −15 V → 0 V로 한정한 기준을 대체한다. 각 branch에서 CCM 1 µA와 선형 보간을 적용하고 MW=|Vth_Program−Vth_Erase|로 계산한다. 다른 진폭에서는 −Vmax→+Vmax와 역방향으로 동일 규칙을 확장하는 안을 적용하되 실제 sweep 경로를 확인한다.
- **Retention VDS:** 0.1 V 고정으로 확인됐다. 읽기 VGS는 새로 추가된 `관련 자료/Retention Plot.pptx`의 슬라이드 2 `Read - V` 표기에서 확인했다. 아래 표를 참조한다.
- **측정 제외:** 소자팀이 측정 문제로 지정한 `R3(2)`만 분석 대상에서 제외한다. PPT에 R3(1)과 R3(2)가 별도로 있고, 기존 A3의 전류 범위·곡선은 R3(1)에 대응하는 것으로 보인다. A3 전체를 제외하지 않으며 원본을 삭제하지 않는다.
- **중간 상태 Retention:** 별도 데이터가 없다고 확인됐다. 소자팀 설명은 1 V 간격 측정에서 Program/Erase 전도도 값이 겹쳤다는 것이다. 이를 모든 상태의 동일한 시간 변화 또는 LTP/LTD 통합 상태의 반복 재현성을 입증한 결과로 해석하지 않는다.
- **파일 확인:** 후속 사용자 요청으로 `관련 자료/Retention Plot.pptx`가 추가됐다. 이후 소자팀이 A5→R5(1), 나머지는 기존 대응이 맞다고 확인했다. 아래 표는 이 확인을 기준으로 하며, 이전 그래프 비교에서 추정했던 A5→R5(2)를 대체한다.

### 새 Retention PPT의 읽기 조건

| PPT 표기 | Read VGS | 기존 엑셀과의 대응 | 처리 |
|---|---|---|---|
| R1 | 0 V | A1 | 사용 |
| R2 | 0 V | A2 | 사용 |
| R3(1) | 0.5 V | A3 | 사용 |
| R3(2) | 0.5 V | 현재 A3와 다른 곡선 | 소자팀 지정 제외 |
| R4(1) | 0.1 V | A4 | 사용 |
| R4(2) | 0.5 V | 해당 원본 엑셀 미식별 | PPT 참고 |
| R5(1) | 0.5 V | A5（소자팀 확인） | 사용 |
| R5(2) | 0.5 V | 해당 원본 엑셀 미식별 | PPT 참고 |
| R5(3) | 0 V | 해당 원본 엑셀 미식별 | PPT 참고 |

대응 관계는 소자팀의 직접 확인을 우선한다. A5→R5(2)라는 이전 추정은 폐기하며 A5→R5(1)로 기록한다. R4(1)의 Read 0.1 V는 기존 Normalized Data 원본 이름의 `0V`와 다르므로 소자팀이 지정한 PPT 표기를 사용하고 출처 차이를 기록한다. 일부 그래프의 가로축 제목이 Gate Voltage로 남아 있지만 본 자료는 Retention 시간 곡선이다. 계산은 엑셀 시간 열을 사용한다.

LTP/LTD의 채택 읽기 구간은 VGS 약 0 V다. 따라서 A3/A4/A5로 추정되는 Retention 조건을 0 V 가중치 상태에 적용하면 읽기 조건 전이 가정이 추가된다. VDS가 모두 0.1 V라는 사실이 이 차이를 없애지는 않는다. 해당 프로필의 장기 정확도 결과에 이 가정을 표시한다.

### 시뮬레이터용 D2D 설계

사용자는 D2D 세부 계산법을 시뮬레이터 목적에 맞춰 설계하도록 위임했다. 기본안은 최대 전류가 아니라 **같은 Gate 읽기점의 전도도 편차**다.

1. 소자팀이 고른 동일 A조건의 서로 다른 두 닷 파일을 받는다. 다른 A조건을 한 D2D 집단으로 섞지 않는다.
2. 각 파일에서 sweep 진폭(1~15 V)과 증가/감소 방향을 식별한다. 행 번호가 같다는 이유만으로 상태를 대응시키지 않는다.
3. 같은 진폭·같은 방향에서 VGS=0 V일 때의 Id를 추출한다. 이는 LTP/LTD 읽기 Gate 전압에 맞춘 선택이다. 정확한 0 V 표본이 없으면 같은 branch의 인접점에서 선형 보간한다. 바깥 범위 외삽이나 서로 다른 방향의 점 연결은 하지 않는다.
4. VDS=0.1 V로 G를 계산한다. 상태 조건 k마다 mean_G[k], 표본 표준편차 s_G[k](분모 N−1), CV[k]=s_G[k]/mean_G[k]를 출력한다. 누락·비양수·유효성 문제는 표시하고 자동 절댓값 변환이나 임의 clipping을 하지 않는다.
5. 두 소자 모두 비교 가능한 조건만 기본 포함 집합 K로 사용한다. 상태 조건별 값과 포함/제외 목록을 보여준다. 표본 부재는 정상 제외 사유로 기록하되 물리적 이상값 판단은 연구자에게 맡긴다.
6. 현재 프로필의 단일 대표값은 **d2d_cv=sqrt(mean_k(CV[k]^2))**로 제안한다. 동일 조건을 같은 비중으로 다루는 상대 분산 평균이며, 조건별 평균 전도도가 다른 상태들을 그대로 섞은 표준편차와 구분된다. 이 대표값은 상태 공통 상대 편차를 가정한 근사다. 전도도 상태 수를 소자 표본 수로 계산하지 않는다. 소자 수는 계속 N=2다.
7. 시뮬레이션에서는 가상 소자별 상대 편차를 배열 생성 때 한 번 생성해 고정한다. 재프로그램할 때 새로 생성하지 않는다. 차동쌍 G+와 G−는 별개 소자로 취급하며 상관 구조와 분포 가정은 실행 설정에 명시한다.

IV sweep 진폭·branch별 상태는 LTP/LTD pulse별 상태와 동일하다고 검증된 것이 아니다. 따라서 이 값은 **IV에서 추정한 대표 D2D**이며, 실측된 모든 LTP/LTD 상태의 D2D라고 표기하지 않는다. 정확도를 올리려면 추후 동일 pulse 목표 상태를 여러 소자에 기록한 자료로 대체한다. 대표값을 작게 만들기 위해 불리한 조건을 제외하지 않는다. 표본 표준편차와 RMS 집계는 설계 기본안이며, 사용자 검토 전 최종 명세로 간주하지 않는다.

소자팀 보조 분석에는 각 진폭별 전류 곡선·최대 전류·MW 비교를 별도로 제공할 수 있다. 이 비교 지표가 시뮬레이터 D2D를 자동으로 대체하지 않는다.

## 1. 사용자 확정 사항

- D2D는 소자팀이 고른 두 번호의 파일을 업로드하여 **전도도 편차**를 계산하고, 검토 후 시뮬레이터에 사용한다.
- 측정 분석은 소자팀 보조 도구로서 제공 PPT에 나온 항목을 모두 포함한다. 시뮬레이터 사용 여부로 기능을 제외하지 않는다.
- Vth는 CCM, 기준 전류 1 µA, 선형 보간을 사용한다. 제공 설명의 기준은 15 V sweep 중 Erase의 −15 V → 0 V 구간이다.
- Retention은 10초 미만 데이터를 분석에서 제외한다. 원본을 삭제하지 않는다.
- LTP/LTD에서 A열은 시간, B열은 Drain 전류, C열은 Gate 전압이다. 시간 6초 이상에서 읽기 구간을 찾는다.
- C열이 0 V 부근에서 다음 쓰기 펄스로 바뀌는 행을 j라 하면 B열의 j−2행을 채택한다. 예: 전환 1024행 → 채택 1022행.
- A1~A5의 LTP/LTD 읽기 VDS는 모두 0.1 V이다. G = Id / 0.1 V로 계산한다. 이 확인을 IV Sweep·Retention의 VDS로 확대 적용하지 않는다.
- 사용자는 LTP/LTD 통합 상태 풀과 Program Retention을 이용한 연 단위 정확도 평가를 원한다. 이 두 항목의 세부 물리 가정은 아래 제안 단계다.

## 2. 자료 확인 결과

### C2C

현재 폴더의 자료에서 같은 물리 소자·동일 목표 상태·동일 읽기 조건에 대한 독립적인 재프로그램 반복을 식별하지 못했다.

- IV Sweep 50개: 조건 A1~A5와 서로 다른 닷 위치별 곡선이다. 설명 PPT는 각 소자에 대해 1~15 V sweep을 한 번씩 수행했다고 설명한다. 다른 진폭·방향을 같은 상태 반복으로 간주할 수 없다.
- LTP/LTD 원본 CSV 10개: 조건마다 방향별 하나의 펄스 궤적이며, 각 12,000개 시간 표본이다. 펄스마다 상태가 변하므로 궤적 전체의 표준편차는 C2C가 아니다.
- Retention 5개: 기록 후 시간 경과에 따른 전류 변화다. 이를 재프로그램 산포로 사용하지 않는다.
- Vth 결과표와 계산기: Vth 추출·요약 자료이며, 전도도 반복 기록 자료가 아니다.

따라서 현재는 **실측 C2C 산출 불가**로 처리하는 것이 타당하다. 미제공을 실측 0으로 저장하지 않는다. C2C를 끈 실험은 ‘C2C 미반영’, 사용자가 가정값을 입력한 실험은 ‘가정 C2C’로 표시한다. 이후 동일 소자에서 같은 목표 상태를 반복 기록한 데이터가 확보되면 계산한다. 하나의 읽기 구간 내 여러 표본은 읽기 산포·안정화 과정이며 C2C 대체값이 아니다.

### LTP/LTD

- LTD는 약 +10 V, LTP는 약 −10 V 쓰기 펄스와 0 V 부근 읽기 구간을 가진다. 파서는 양·음 방향을 모두 감지해야 한다.
- 읽기 전류를 G로 바꾸는 데 VDS=0.1 V를 사용하며 Gate 전압으로 나누지 않는다.
- 임시 검사에서는 |Vg|>5 V를 펄스 판별에 사용했다. 이는 원자료 확인용이며 최종 임계값·히스테리시스 규칙을 확정한 것이 아니다.
- 해당 검사로 시간 및 j−2 조건을 적용하면 파일당 내부 표본 510개가 추출된다. 파일명의 512를 유효 상태 수라고 가정하면 안 된다. 시작·마지막 펄스 및 후속 전환 없는 마지막 읽기 구간 처리를 명세에서 정해야 한다.
- 이 내부 표본 기준 A1의 LTD는 약 11.4~115 µS, LTP는 약 348~495 µS로 분리되어 있다. 통합하더라도 중간에 실측되지 않은 상태를 생성하지 않는다.
- A1~A5는 설명 PPT의 ‘조건번호’이다. 서로 다른 조건을 하나의 소자 상태 풀로 섞지 않는다.
- `~$` 임시 파일은 분석 입력에서 제외한다.

### Retention

- 10초 미만 제외 시 각 조건·방향에 100개 표본, 약 10~1,000초가 남는다.
- `Normalized Data`는 전류 비율이 아니라 첫 유효 전류를 뺀 I(t)−I(t0)이다. Raw Data와 수치 대조했다.
- PPT의 A1 피팅 계수는 원자료에 I(t)=a+b·log10(t)를 최소제곱으로 적합한 값과 일치한다. t 단위는 초다.
- Program 전류는 A1~A5 모두 관측 구간에서 증가한다. 전류 손실 또는 정확도 감소를 사전에 강제하지 않는다.
- 읽기 조건은 추가 확인이 필요하다. Normalized Data의 원본 이름에는 read_retention_0V와 0.5V가 섞여 있으며, 이 문자열만으로 어떤 단자의 전압인지 확정하지 않는다.

## 3. D2D 계산 제안

두 소자가 같은 상태 정의·읽기 VGS/VDS·sweep 방향 또는 프로그램 조건에서 비교되어야 한다. 서로 다른 상태의 모든 전류값을 묶어 표준편차를 구하지 않는다.

제안 출력:

- 채택한 소자 번호·상태·읽기 조건·원본 행
- 소자별 G, 평균 G, 표본 표준편차 sG, 상대 표준편차 sG/mean(G)
- 소자 수 N=2와 표준편차 분모 N−1 사용 여부
- 상태별 값을 하나의 대표값으로 축약했다면 그 규칙

표본 표준편차 사용은 제안이며 소자팀 기준과 합의한다. 두 소자 결과는 두 소자 기반 추정이며 전체 소자군 분포가 검증되었다고 표현하지 않는다. 단일 상태에서 얻은 CV를 전체 상태에 공통 적용한다면 상태 공통 근사라고 표시한다. IV 파일을 쓸 경우 LTP/LTD와 별개로 IV 읽기 조건을 확인한다.

## 4. 전도도 풀과 가중치 매핑 제안

물리적으로 Vth가 저장 상태와 연결되더라도, 현재 추론 모델에서 수치 가중치는 읽기점의 G 또는 G+−G−로 표현한다. Vth를 신경망 가중치와 같은 수치로 놓지 않는다. 한 읽기 바이어스에서 측정한 G는 해당 바이어스의 유효값이며 실제 트랜지스터의 전체 입력 응답을 검증한 것은 아니다.

1. A1~A5 프로필별로 LTP/LTD의 읽기 전류를 각각 추출한다.
2. 각 후보에 방향, 펄스 순서, 소자 위치, 초기화 조건, 원본 행, Id, VDS, G를 보존한다.
3. 동일 프로필 안에서 두 방향을 합친 유한 후보 풀을 구성한다. 다른 조건 프로필은 별도 비교한다.
4. 수치가 정확히 같은 G는 매핑 인덱스에서 묶을 수 있지만 원본과 도달 경로는 보존한다. 비슷하다는 이유로 임의 평균하거나 평활하지 않는다.
5. Gmin/Gmax는 채택 풀과 일치하도록 검증한다. 상태 수는 표본 수와 별도로 표시한다. 반복성이 확인되지 않은 후보를 모두 ‘구분 가능한 안정 상태’로 단정하지 않는다.

기본 매핑 제안은 한쪽을 Gmin에 고정하는 차동쌍이다. w=s(G+−G−)로 표현하며, 양수 가중치는 G−=Gmin, 음수 가중치는 G+=Gmin으로 두고 다른 쪽의 목표를 실측 풀의 가장 가까운 G로 선택한다. s는 레이어/타일별로 기록하고 부호·복원 스케일을 일관되게 사용한다.

임의의 두 상태 조합에서 가중치 오차를 최소화하는 방식은 비교 실험 후보로 둔다. 이 방식은 공통 전류와 소자 편차 민감도가 달라지므로 오차가 작다는 이유만으로 기본안으로 확정하지 않는다. LTP/LTD 각 단독 풀과 통합 풀의 ‘매핑만 적용한 정확도’를 먼저 비교한다.

후보 통합은 각 목표 상태를 그 도달 경로로 다시 쓸 수 있다는 가정이 필요하다. 현재 자료만으로 반복 재현성과 상태 구별 능력이 입증되지는 않았다. 입력 신호를 Gate로 인가하는 실제 회로를 평가하려면 추가 전달 특성 및 회로 정의가 필요하며, 현재 단계는 고정 읽기점의 유효 G를 사용하는 추론 근사다.

## 5. Program-only Retention 제안

시뮬레이터에서 Erase를 끄고 Program 곡선만 선택할 수 있도록 한다. 측정 분석 페이지에서는 PPT 범위대로 양쪽 곡선을 계속 제공한다. Program이라는 이름을 LTP 전체와 동일시하지 않는다. 실제 CSV의 LTP는 음전압 펄스이고 Retention Program은 +15 V 조건이므로 경로·초기화·읽기 조건의 대응을 확인해야 한다.

### 우선 가능한 실험: Program 기반 민감도 시나리오

- I_fit(t)=a+b·log10(t)를 적합한다. 기준 시점 t_ref는 10초 등으로 명시한다.
- r(t)=I_fit(t)/I_fit(t_ref)를 구한다. 기준값이 양수인지 확인한다.
- 전체 상태에 공통 비율을 적용하는 가정 아래 G_s(t)=G_s(t_ref)·r(t)로 변환한다.
- 입력 years는 기준 시점 이후 경과 연수로 정의하고 t_target=t_ref+years×365.25×86400으로 변환한다. 재프로그램 횟수 n과 다른 필드로 저장한다. years=0은 기준 시점 평가로 처리하므로 log10(0)을 계산하지 않는다.
- 가중치와 매핑 스케일을 기준 시점에 고정한 후 시간별 전도도로 재추론한다. 각 시점마다 다시 최적 상태로 매핑하거나 자동으로 정규화하지 않는다.
- 실험 시작 때 뽑은 D2D와 해당 프로그램 회차의 C2C를 같은 시간 곡선 동안 유지한다. 시간마다 재프로그램하지 않는다.
- 결과는 기준 정확도, 목표 시점 정확도, 차이(%p), 예측 전류/전도도, 측정 범위/외삽 범위를 보여준다. 정확도 차이의 부호를 보존한다.

이 시나리오는 Program 상태 하나의 변화 비율을 모든 상태에 확장한 **가정 기반 실험**이며 전체 다중 상태 Retention의 실측 검증 결과가 아니다. LTP/LTD 읽기 시점과 Retention의 10초 기준도 현재 일치가 확인되지 않았으므로, LTP/LTD G를 t_ref 값으로 간주하는 것 자체를 가정으로 기록한다.

같은 절대 ΔG를 G+와 G− 양쪽에 더하면 차이에서 상쇄된다. 공통 비율을 곱하면 차동 가중치도 같은 비율로 바뀌어 공통 이득 변화가 된다. 보정으로 회복되는 변화와 상태별 열화는 구분한다. 따라서 자동 drift/gain 보정은 기본 비교에서 끄고, 보정 사용 시 별도 실험으로 보고한다.

측정은 약 1,000초까지만 있다. 참고로 같은 로그식을 1년까지 외삽하면 Program 전류 비율은 조건에 따라 약 2.18~7.07배가 된다(10초 피팅값 대비, 1년=365.25일). 이는 장기 실측 사실이 아니라 가정의 민감성을 보여주는 산술 결과다. 유효 범위를 벗어나거나 비물리적 예측이 생기면 표시하고, 임의 clipping으로 감추지 않는다.

더 충실한 정확도 예측은 여러 채택 G 상태에 대한 Program 기반 Retention 곡선과 동일한 읽기 조건을 확보한 뒤 상태 의존 모델로 확장한다. 소자 간 시간 산포까지 주장하려면 반복 측정도 필요하다.

## 6. 측정 분석 전체 범위

`관련 자료/엑셀 데이터에 대한 간단 설명.pptx`의 출력 네 항목을 모두 포함한다.

| 기능 | 입력 및 계산 | 미확정 부분 |
|---|---|---|
| Vth 및 평균 | IV Sweep, CCM 1 µA, 선형 보간, 파일별 값 및 유효값 평균 | 예외 파일의 sweep 선택·다중 교차 처리 |
| Memory window 및 평균 | 같은 소자의 두 상태 Vth 차이와 소자별 결과 평균 | Program 쪽 sweep branch 및 부호/절댓값 규칙 |
| D2D 전도도 표준편차 | 사용자가 고른 두 소자, 같은 읽기 조건의 G | 비교 상태·IV VDS·대표 CV 축약 규칙 |
| Retention 기울기 | Erase/Program 각각 10초 이상, 로그 시간 피팅, 표·그래프 | 장기 모델 적용 범위·추가 통계 표시 |

표·그래프와 계산 조건, 제외 사유, 표본 수 및 결과 파일 내보내기를 함께 제공한다. C2C는 현재 PPT 필수 출력에 없으며 데이터가 확보되면 확장한다. EPSC/IPSC·PPF/PPD 등은 이 PPT의 네 항목에 포함되지 않으므로 자동으로 이번 필수 범위에 추가하지 않는다.

## 7. 정확도 평가 단계 제안

| 실험 | 반영 요소 | 목적 |
|---|---|---|
| D0 | 원본 디지털 모델 | 기준 정확도 |
| M0 | 유한 전도도 매핑만 | 상태 풀·매핑에 의한 손실 |
| D1 | M0 + D2D | 소자 간 편차 영향 |
| C1 | M0 + C2C 가정/실측 | 재프로그램 편차 단독 영향; 미제공 시 생략 |
| R1 | M0 + Program Retention 시나리오 | 시간 변화 단독 영향 |
| H1 | M0 + ADC 정밀도 sweep | 변환기 양자화 영향 |
| H2 | M0 + 명시적 타일 크기/입출력 범위 | 타일링 및 포화 영향 |
| ALL | 선택한 요소 조합 | 상호작용을 포함한 종합 정확도 |

모델·체크포인트·데이터셋·seed·입출력 스케일 정책은 비교 실험 사이에서 통제한다. 손실을 단순 합산하지 않고 조합을 실제로 추론한다. 전체 조합에서 필요하면 요소 하나씩 제외한 실험으로 원인을 확인한다.

AIHWKit 기본 PCM noise, drift, 보정 및 기본 forward noise가 CTFM 데이터와 중복되지 않도록 명시적으로 설정한다. 물리 계수가 없는 wire resistance, read noise, 비선형 응답 등을 단지 도구에 있다는 이유로 동시에 켜지 않는다. DAC, ADC, 포화, 출력 스케일, 타일링을 실험 설정과 결과에 기록한다.

NeuroSim은 같은 매핑·배열·ADC·소자 범위·읽기 조건에 대한 PPA를 추정한다. NeuroSim 자체 정확도 계산을 AIHWKit 정확도에 추가 손실로 합산하지 않는다. 두 엔진의 표현 가능한 설정 차이는 검증하고, 맞추지 못한 차이는 결과에 표시한다. Retention 시점별 PPA를 재실행하지 않으면 초기 조건의 PPA로 표기한다.

기술 근거는 동반 문서 `cim-nonideality-design-research.md`에 기록한다.
