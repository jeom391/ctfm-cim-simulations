# MNIST 실측 상태 매핑 기준 실험

2026-09-17. 사용자가 현재 관측 범위를 명시한 MNIST 첫 구현을 승인했다. 이 문서는 해당 실행 범위의 명세이며 전체 웹 서비스 명세를 대체하지 않는다.

## 실험 범위

현재 1 ms ON / 1 ms OFF, 유한 펄스 수의 관측 상태로 사전학습 MLP의 추론 정확도를 비교한다. 수렴 도달 여부는 미확인이다. 관측 Gmin/Gmax를 소자의 포화 범위 또는 최고 가능 성능으로 표현하지 않는다.

- 원본 MNIST: 학습 파일 60,000개 중 고정 seed로 55,000 학습 / 5,000 검증 분리. 공식 테스트 10,000개는 설정 선택에 사용하지 않는다.
- MLP: 784→128→10, ReLU, 입력 픽셀 /255, 디지털 bias. Adam, 학습률 0.001, 기본 5 epochs. 마지막 epoch 체크포인트 하나를 모든 프로필에 공유한다.
- A1~A5의 LTP / LTD / 통합 풀 각각 평가한다. 파일명 512를 유효 상태 수로 사용하지 않는다.
- 매핑: Gmin 고정 차동쌍과 실측 두 상태 조합 비교. 레이어별 max|w|와 관측 G 범위로 scale을 결정한다. 임의의 새로운 G나 MW 기반 범위 확대는 하지 않는다.
- 검증 정확도로 프로필별 후보를 선택한다. 동률은 명시된 후보 순서로 결정한다. 선택을 고정한 뒤 모든 후보의 테스트 결과와 선택된 결과를 보고한다.
- D2D, C2C, Retention, ADC/DAC, 회로 잡음, drift 보정은 이번 기준 실험에서 미반영한다. 0으로 측정되었다는 뜻이 아니다.
- 기본 실행은 PyTorch의 유효 가중치 참조 추론이다. AIHWKit 순전파 검증은 선택 엔진으로 분리하며, 설치되지 않으면 명확히 실패한다. NeuroSim PPA는 이번 단계에서 실행하지 않고 `not_run`으로 표시한다.

## CSV 파싱

원본을 변경하지 않는다. UTF-8 또는 CP949 파일의 Time 헤더를 찾아 A/B/C를 읽는다. 단위는 초/A/V다. 임시 `~$` 파일을 제외한다. 숫자 누락, 비유한 값, 시간 역전은 오류로 보고한다.

기본 검출은 |VGS|<=0.05 V를 읽기 구간으로 본다. 읽기 구간을 벗어난 연속 구간이 |VGS|>=5 V에 도달하면 실제 쓰기 펄스로 확인한다. 그 구간의 시작 행 j를 전환 시작점으로 사용한다. 이렇게 해야 0→중간 전압→10 V로 이동하는 펄스에서도 경계가 늦춰지지 않는다. 임계값은 설정에 기록한다. j−2행 B를 선택하되 j−2와 j−1이 읽기 구간이고 선택 시점이 6초 이상이어야 한다. LTD 양전압과 LTP 음전압을 모두 검출한다. 조건을 충족하지 않는 전환은 사유를 기록한다. 다음 전환 없는 마지막 읽기 구간은 이번 규칙으로 선택하지 않는다. 이전 문서의 단순 |VGS|>5 V 진단보다 일부 표본의 선택 행이 앞당겨질 수 있으므로 실행 결과의 원본 행 목록을 기준으로 한다.

G=Id/0.1 V. 계산은 SI 단위 S, 보고는 µS. 채택 상태마다 원본 행·전환행·시간·Gate 전압·전류·방향·파일 SHA256을 보존한다. 수치가 같은 후보를 매핑 인덱스에서 묶어도 원본 표본은 모두 내보낸다. 고유 숫자 개수는 검증된 물리 상태 수가 아니다.

## 매핑

풀의 폭 ΔG와 레이어 최대 절댓값 W를 사용해 scale=W/ΔG, w_hat=scale(G+−G−)로 복원한다. W=0인 레이어도 0 가중치가 되도록 처리한다.

Gmin 고정은 부호에 따라 한쪽을 Gmin, 다른 쪽을 가장 가까운 측정 후보로 선택한다. 일반 쌍은 두 실측 후보의 차이가 목표에 가장 가까운 조합을 선택한다. 동률은 낮은 공통 전도도, 이후 후보 인덱스 순서로 결정한다. 음수는 쌍을 뒤집는다. 모든 G는 실제 후보 집합에 속해야 한다.

독립적으로 원하는 두 상태를 기록할 수 있다고 가정한다. 원본 경로와 후보 인덱스를 저장하므로 이 가정을 추적할 수 있다. 잡음 이후에도 같은 성능이 유지된다고 주장하지 않는다. 각 레이어의 매핑 오차와 scale도 보고한다.

## 재현성과 산출물

설정 JSON, Python·NumPy·PyTorch/AIHWKit 버전, seed, 소스 코드 해시, 입력 CSV 해시, MNIST 압축 파일 해시, 분할 인덱스, 모델 체크포인트·해시, 매핑된 전도도 쌍, 후보별 검증/테스트 정확도, 정확도 손실(%p)을 저장한다.

MNIST 다운로드는 torchvision 공식 소스에 기재된 OSSCI mirror와 MD5를 사용하며, 로컬 파일이 이미 있어도 무결성을 검사한다. 체크포인트 재사용은 split·학습 설정과 소스 해시가 일치할 때만 허용한다. 출력 폴더가 이미 있으면 덮어쓰지 않는다.

출력은 `runs/<사용자 지정 이름>/`의 JSON·CSV·Markdown 및 재현 artifact다. 실행 도중 실패하면 완료 결과로 표시하지 않는다. 연구 비교는 단일 seed 기준이며 통계적으로 일반화된 성능으로 해석하지 않는다.

## 검증

합성 CSV로 양·음 펄스, 6초 경계, j−2 선택, 마지막 구간 제외, 인코딩·오류 처리 검증. 수동 계산 가능한 G 후보로 부호·0·끝점·동률·차동쌍 보존을 검증. 실제 A1 파일의 첫 채택 행은 1022행이며 LTD 전류는 1.15e−5 A다. MNIST 실제 학습·추론을 실행하고 단위 테스트와 결과 스키마를 확인한다.
