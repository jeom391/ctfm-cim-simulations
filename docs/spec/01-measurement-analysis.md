# 측정 데이터 분석 명세

버전 `1.0.0` · [개발 시작](README.md)

## 입력과 공통 규칙

CSV/XLSX를 지원한다. CSV는 UTF-8(BOM 포함), CP949 순서로 엄격 디코딩한다. XLSX는 선택한 시트와 열을 명시한다. 자동 인식은 미리보기용이며 인식되지 않은 형식을 임의 추정해 계산하지 않는다. `~$` 임시 파일은 제외한다. `.xls`는 v1에서 지원하지 않으며 XLSX 변환 안내를 반환한다.

업로드마다 SHA256, 원본명, 시트, 실제 1-based 행 번호, 단위, 열 매핑, 측정 조건을 기록한다. 계산 단위는 A/V/S/s이며 화면에서 µA/µS를 지원한다. 불일치 단위를 묵시적으로 섞지 않는다. 빈 셀·비수치·비유한 값·시간 역전은 해당 데이터셋 오류다. 전류 부호를 자동 절댓값 처리하지 않는다. 원자료는 보존한다.

분석 공통 산출물: 사용 조건, 원본 및 추출 표, 그래프, 포함/제외 사유, 표본 수, 경고, CSV/XLSX/JSON 다운로드. 그래프 PNG도 제공한다. XLSX 수식만 있고 캐시 값이 없으면 임의 0으로 읽지 않고 재저장 또는 원시 값 업로드를 요청한다.

## Vth와 Memory Window: 필수

IV 입력은 소자 ID·A조건·sweep 진폭·branch·VGS·ID·VDS를 식별할 수 있어야 한다. 파일/시트/구간 선택으로 명시적 column mapping을 저장한다. 증가 branch는 Erase, 감소 branch는 Program이다. 진폭 1~15 V별로 분리하고 각 branch 전체 범위를 사용한다. 시간순 곡선을 전압순 재정렬해 다른 branch를 섞지 않는다. sweep 전환 경계 표본은 양 branch의 끝점으로 공유할 수 있으나 중복 sweep로 세지 않는다.

CCM 기준 전류 `Iref=1e-6 A`, VDS=0.1 V. 인접 두 표본에서 선형 보간한다:

`Vth = V1 + (Iref-I1)*(V2-V1)/(I2-I1)`

정확한 일치점 하나는 그 VGS를 사용한다. 동일 교차의 끝점 중복은 한 번만 센다. 교차 없음은 `no_crossing`, 서로 다른 교차 여러 개/기준 전류 plateau는 `ambiguous_crossing`으로 자동 확정을 중지한다. 사용자가 인접 구간을 지정하면 그 선택과 이유를 기록한다. 외삽하지 않는다.

같은 소자·같은 진폭의 `MW=abs(Vth_Program-Vth_Erase)`. 진폭별 유효 소자 Vth 평균과 MW 평균을 각각 산출한다. `abs(mean(Vth_P)-mean(Vth_E))`로 MW 평균을 대체하지 않는다. N=1이면 평균은 허용하되 표본 표준편차는 null이다. 1~15 V별 최대 ID(각 branch의 실제 signed maximum)와 MW 비교도 제공한다. 최대 ID는 D2D 대표값으로 자동 사용하지 않는다.

## D2D: 두 소자의 전도도 편차

연구자가 동일 A조건의 서로 다른 물리 소자 두 개를 선택한다. VDS=0.1 V와 읽기 조건의 일치를 검증한다. 같은 진폭·branch를 조건 k로 대응시킨다. 각 branch에서 VGS=0 V의 ID를 정확점 또는 인접 선형 보간으로 구하고 G=ID/0.1로 변환한다. 다중 교차/전압 plateau의 선택 모호성은 Vth와 동일하게 명시적 구간 선택으로 해결한다. 외삽하지 않는다.

각 조건에서 `meanG=(G1+G2)/2`, `sG=sqrt(((G1-meanG)^2+(G2-meanG)^2)/(2-1))`, `CV=sG/meanG`를 계산한다. 양쪽 모두 유효하고 G>0인 조건만 대표 집합 K에 포함한다. 누락·비양수·읽기 조건 불일치와 사용자 제외를 기록한다. 조건별 산포를 원래 표와 함께 보존한다.

대표값은 `d2d_cv=sqrt(sum(CV[k]^2)/len(K))`, 조건별 동일 가중치다. K가 비면 산출 불가다. 소자 표본 수는 항상 2이며 sweep 개수로 늘리지 않는다. `source_kind=iv_proxy`, `distribution=assumed_lognormal`을 기록한다. 분포 형태와 상태 공통 적용은 실측에서 식별한 사실이 아니다.

## LTP/LTD 후보 추출

A열 time(s), B열 ID(A), C열 VGS(V). 헤더를 검출한 뒤 실제 행을 보존한다. 메타데이터에 A조건과 LTP/LTD를 지정한다. 현재 자료의 읽기 목표 VGS=0 V, VDS=0.1 V, LTP 음의 쓰기 펄스/LTD 양의 쓰기 펄스다.

1. `abs(VGS)<=0.05 V`를 읽기 구간으로 판정한다.
2. 읽기 구간을 벗어난 연속 구간이 `abs(VGS)>=5 V`에 도달하면 쓰기 펄스로 확인한다. 극성을 검증한다.
3. 해당 구간의 첫 행 j를 전환 시작으로 사용한다. 중간 전압을 지나더라도 5 V 도달 행으로 시작을 늦추지 않는다.
4. j-2와 j-1이 모두 읽기 구간이고 j-2의 시간이 6초 이상이면 j-2행의 ID를 채택한다. 예: 1024행에서 전환하면 1022행을 사용한다.
5. 다음 전환이 없는 마지막 읽기 구간, 앞쪽 표본 부족은 제외 사유를 남긴다. G<=0은 프로필 후보에서 제외하고 분석 표에는 남긴다.

위 임계값은 parser 설정으로 저장한다. 원본 순서·파일 해시·행·전환행·시간·방향·전류·VGS·G를 유지한다. 펄스 번호를 알 수 없으면 `pulse_step=null`과 별도 extraction index를 쓴다. 파일명의 512나 추출 index를 검증된 누적 pulse_step으로 간주하지 않는다.

초기 전류 subtraction, 이동평균, 누적최대/최소, 포화 구간 평균, 자동 단조화는 기본 추출에 적용하지 않는다. 진단 그림에 추세선을 추가해도 원시 후보를 바꾸지 않는다. 같은 숫자의 G는 검색용 인덱스에서만 묶고 모든 원본 참조를 보존한다.

## 상태 풀

각 A조건별 `ltp`, `ltd`, `combined`, `common`을 생성한다. combined는 실측 후보 합집합이다. common의 범위는 `lo=max(min(LTP),min(LTD))`, `hi=min(max(LTP),max(LTD))`이며, 그 닫힌 구간 안의 양방향 실측 후보 합집합을 쓴다. lo>=hi 또는 유효 고유 후보 2개 미만이면 매핑 불가다. 범위 교집합이므로 양방향에 동일 G가 실제 관측됐다는 의미는 아니다.

각 풀의 Gmin/Gmax는 실제 채택 후보의 min/max다. 교집합 lo/hi와 별도 필드로 보존한다. 후보가 없는 경계값을 생성하지 않는다. common은 보수적인 범위 비교이며 가역적 pulse update 검증이 아니다. 기존 AI 계산의 범위·alpha·상태 수 12/10/15 등은 참고값이고 재계산 결과를 대신하지 않는다.

## Retention: 필수 분석, 가정 기반 추론 입력

Raw Data의 time/Program ID/Erase ID를 사용한다. `Normalized Data`의 초기 전류 차감값을 절대 전류로 오인하지 않는다. t<10 s 제외, 양 방향 각각 `I_fit(t)=a+b*log10(t/1 s)`를 OLS로 적합한다. 서로 다른 시간점 3개 이상, 유한 값이 필요하다. 출력: a(A), b(A/decade), RMSE(A), R²(총분산 0이면 null), 측정 시간 범위, N, 잔차와 곡선. 선형시간 순간 기울기는 `b/(t*ln(10)) A/s`로 별도 표기한다.

| 프로필 | Retention 식별자 | 읽기 VGS | VDS |
|---|---|---:|---:|
| A1 | R1 | 0 V | 0.1 V |
| A2 | R2 | 0 V | 0.1 V |
| A3 | R3(1) | 0.5 V | 0.1 V |
| A4 | R4(1) | 0.1 V | 0.1 V |
| A5 | R5(1) | 0.5 V | 0.1 V |

R3(2)만 소자팀 지정 제외이며 A3 전체를 제외하지 않는다. A5=R5(1)은 소자팀 확인을 따른다. 읽기 조건은 소자팀이 지정한 Retention PPT를 우선하고 원본 헤더 차이를 provenance에 기록한다. A3/A4/A5의 0 V 펄스 상태에 Retention을 옮기는 것은 읽기 바이어스 전이 가정이다.

C2C, EPSC/IPSC, PPF/PPD, 내구성 산출은 v1 필수 기능이 아니다. 새 보고서의 참고 문헌 그림은 추가 측정 데이터로 취급하지 않는다.
