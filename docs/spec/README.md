# 개발 시작: CTFM 측정 분석 및 CIM 시뮬레이터

문서 묶음 버전: `1.0.2` (계산·API schema `1.0.0` 유지) · 확정일: 2026-09-18 · 상태: **구현 기준 확정, 구현 완료를 뜻하지 않음**

## 제품 범위

홈에서 `측정 데이터 분석`과 `CIM 시뮬레이션` 두 페이지로 이동한다. 분석은 소자팀이 반복 계산에 쓰는 독립 도구다. 시뮬레이터에 쓰이지 않는 Vth·Memory Window 분석도 포함한다. 분석 결과를 사용자가 검토하고 프로필로 발행한 뒤 시뮬레이터에서 선택한다. AI API로 이상값, 비교군, 유효 상태를 자동 결정하지 않는다.

## 확정 결정

- A1~A5를 각각 평가한다. 서로 다른 A조건의 전도도 목록을 하나의 소자 풀로 합치지 않는다.
- 동일 조건의 LTP/LTD는 절대 읽기 전류를 사용한다. 초기 전류를 빼는 offset을 적용하지 않는다. G=ID/VDS, VDS=0.1 V다.
- 1 ms 펄스 폭, 1 ms 간격, 512회 인가는 측정 조건이다. 포화 도달·512개 구별 가능한 상태를 의미하지 않는다.
- 기본 풀은 같은 A조건의 LTP/LTD 실측 후보 합집합이다. 방향 단독 풀과 공통 범위 풀도 비교한다. 공통 범위가 없는 A1/A2도 단독·합집합 평가는 가능하다.
- 기본 가중치 표현은 Gmin 고정 차동쌍이다. 두 상태 조합 탐색을 비교 옵션으로 제공한다. 보간으로 만든 전도도나 분수 펄스를 실제 기록 상태로 쓰지 않는다.
- D2D는 연구자가 고른 동일 A조건의 두 소자에서 추정한다. IV 기반 대표 편차를 펄스 상태에 전이하는 모델 가정을 표시한다.
- C2C는 현재 미제공으로 미반영한다. 실측 0 또는 없다고 증명된 값으로 저장하지 않는다. 재프로그램 반복 수는 1로 고정한다.
- Retention 분석은 Program/Erase 모두 제공한다. 추론 시간 변화는 Program 곡선의 공통 비율을 모든 전도도에 적용하는 가정 실험으로 제공한다.
- PyTorch는 디지털 및 결정적 참조 계산, AIHWKit은 아날로그 정확도, NeuroSim은 PPA 추정을 담당한다. 엔진 실패를 다른 엔진의 성공으로 숨기지 않는다.
- 기준 MNIST MLP, 측정 상태 매핑, 비이상성 단독, 조합 평가 순서로 개발한다. 정확도 하락을 인위적으로 유도하거나 사전 보장하지 않는다.

## 실측으로 입증하지 않은 것

공통 구간만으로 임의 상태 간 양방향 기록 가능성·재현성이 입증되지 않는다. 관측 Gmin/Gmax는 소자의 절대 한계가 아니다. Memory Window로 가상의 전도도 범위를 늘리지 않는다. 고정 읽기점 유효 G를 선형 MAC에 사용하는 것은 회로 근사다. 실제 입력 단자·파형에 따른 비선형 전달 특성, 상태별 장기 보존, C2C, 내구성 열화는 현재 검증 범위 밖이다.

## 변경 관리

규칙 변경 시 이 명세 버전과 관련 스키마 버전을 올리고 변경 이유를 기록한다. 계산으로 얻을 G 범위·상태 개수·피팅 계수·정확도는 설계 미결정 사항이 아니라 구현 산출물이다. 결과가 기대와 다르다고 원자료·상태 선택·테스트셋을 사후 변경하지 않는다.

원본 데이터, 팀 보고서, 개인 경로, 실제 실행 산출물은 Git에 올리지 않는다. Git에는 명세·코드·합성 fixture만 포함한다. 과거 검토 자료는 근거를 추적하기 위한 참고 자료이며 새 명세를 대체하지 않는다.

## v1.0.2 변경

ADC/배열 조건은 사용자 선택값이며 H1/H2는 추천 preset임을 명시했다. NeuroSim V1.4의 SRAM 기본값과 노드별 ADC 읽기 전압 제약을 반영해 0.1 V 단순 대입 방침을 정정했다. 계산/API 기존 필드 버전은 유지한다. 신규 회로 옵션은 [검토 문서](../neurosim-user-controls-review.md)의 제안이며 구현 완료를 뜻하지 않는다. C2C 확장은 별도 측정 방법/입력 계약 확인 후 반영한다.
