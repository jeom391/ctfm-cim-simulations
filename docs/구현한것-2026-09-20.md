## A. 셀과 비용 전제

### A1 셀 모델 — 완료
`measured_conductance_1t1r_proxy_v1`로 구현했습니다. NeuroSim RRAM + CMOS access 읽기 경로를
쓰고, 가중치는 측정 전도도 쌍으로 매핑합니다. 빌드 설정에서 `memcelltype=2`(RRAM),
`accesstype=1`(CMOS_access)을 명시적으로 고정합니다.
`MODEL_MISMATCHES`가 "CTFM을 RRAM과 물리적으로 동일시하지 않음"을 모든 결과에 기록합니다.
→ `ctfm/adapters/neurosim.py`, `neurosim_build.py`

### A2 셀 치수 — 완료
엔진 기본 4F×12F, access gate 1.1V를 baseline 가정으로 쓰고 실측 치수로 표기하지 않습니다.
접근 소자 성립 검사에 실패하면 수치를 내지 않고 비용 평가 실패로 보고합니다.

### A3 접근 구조 — 완료
CMOS access 1.1V baseline. 측정 VGS와 분리해 기록합니다. `accesstype`이 빌드 캐시 key에
포함되므로 다른 접근 구조는 다른 바이너리·다른 결과가 됩니다.

### A4 공정 — 완료
22nm LSTP 300K 고정. `technode=22`, `temp=300`을 컴파일 타임에 고정하고 effective 설정으로
재확인합니다. 소자팀에 공정 선택을 요청하지 않습니다.
**readVoltage는 엔진이 technode 표에서 유도**(22nm → 0.55V)하므로 패치하지 않고 파생값으로
기록합니다.

### A5 차동 비용 — **부분 구현**
- **완료**: 두 plane 구조 집계(`circuit_inventory`) — 물리 셀 `2·R·C`, plane당 가중치 1 셀,
  bit slicing 없음, 타일/plane별 ADC 수, 추론당 변환 cycle.
- **완료**: 합성 규칙(`compose_differential_cost`) — per-plane 블록은 두 plane 합산, shared
  블록은 1회, 지연은 `max(plane) + 공통 누산·차감`. **전체 2배 금지**를 테스트로 고정.
- **미완**: 합성에 넣을 블록별 SI 값. 사유는 별도 문서 참조.
- 누락 front end는 `partial` + `missing_components` + 총계 null로 보고합니다.

### A6 전압 — 완료
측정 0.1V 유지, 비용은 0.55V 선형 G 전이 **가정 명시**. `assumptions`와 PPA 라벨에 노출되며
"검증된 실제 소자 비용"으로 표기하지 않습니다.

### A7 쓰기/읽기 — 완료
read datapath 비용만 산정하고 쓰기 에너지·시간·program/erase 전용 회로 면적은
`excluded_by_scope`로 명시 제외합니다.
**1ms 일괄 거부를 제거**하고 출처 검사로 바꿨습니다(`read_window_problems`): 쓰기 펄스로
표기된 출처나 선언된 `write_pulse_width_s`와 같은 값은 크기와 무관하게 거부하고, 읽기로 출처가
명시된 1ms는 허용합니다. 출처 미기재는 검사 불가이므로 `read_pulse_width_source`를 필수
필드로 추가했습니다.
10ns 가정 대비 settling/ADC 시간 검사는 `schedule_feasibility`로 분리했습니다.

## B. ADC와 입력

### B1 ADC 종류 — 완료
current-mode MLSA 내부 고정(`SARADC=0`, `currentMode=1`). signed 차감 front end는 별도 모델이
필요하다는 사실을 `missing_components`로 보고합니다.

### B2 공유 열 — 완료
경로별 8열 고정(`numColMuxed=8`). 집계에서 타일/plane당 ADC 수 = `ceil(열수/8)`로 계산합니다.

### B3 bus — 완료
XY bus 내부 고정(`globalBusType=0`). H-tree preset은 다른 key로 다른 빌드가 됩니다.

### B4 partial parallel — 완료
사용자 옵션에서 제외했습니다. bit별 한 tile 활성 행 병렬 합산을 우리 adapter로 구현했습니다
(`operationmode=2` → `parallelRead` 파생). 공식 wrapper의 MLC 지원으로 오인하지 않도록
`cells_per_weight` mismatch를 항상 기록합니다.

### B5 입력 정밀도 — 완료
unsigned 8bit, LSB부터 고정 8 cycle bit serial, 전부 0인 cycle도 skip하지 않습니다.
기존 signed trace 경로를 제거했습니다. MNIST/ReLU 한정(음수 입력은 거부).
`q=clip(floor(255x/r+0.5),0,255)`, r은 픽셀 1 / hidden은 디지털 checkpoint의 validation 5k
ReLU 최댓값으로 고정.

### B6 보정 — 완료
upstream `validated=false` baseline 유지, 별도 실리콘 보정 계수를 적용하지 않습니다.
`validated_for_ctfm`은 승인 표시로 설정하지 않으며 CTFM 검증 여부와 분리해 기록합니다.

## C. 실행 환경

### C1 설정 전달 — 완료
`ctfm/adapters/neurosim_build.py`. 설정별 격리 빌드·캐시를 구현했습니다.
- key = upstream commit + patch hash + resolved config + compiler/version/flags + target platform
- 임시 디렉터리에서 빌드 후 **단일 rename으로 원자적 등록**, 같은 key 동시 빌드는 디렉터리 lock
- 패치된 소스를 **다시 읽어** 요청과 다르면 실패 (`levelOutput = 2^adc_bits` 포함 16개 필드)
- 엔진이 파생시키는 값(`parallelRead`, `readVoltage`, `numRowParallel`, `dumcolshared`)은
  패치하지 않고 기록
- 조건부 재대입(`cellBit`은 SRAM에서 1로 강제 등)이 이 설정에서 성립하면 **빌드 거부**

**실제 g++ 13.3으로 검증**: 첫 빌드 3.9초, 재요청 캐시 히트, ADC bits가 실제로 다른 회로를
만드는 것을 수치로 확인(3/5/8 bit에서 ADC 면적 3.09e-8 / 6.35e-8 / 3.77e-7 m²).

### C2 엔진 crash — 완료 (원인 규명 및 가드 정정)
최소 재현(`scripts/linux/repro_neurosim_crash.py`)과 경계 측정
(`scripts/linux/probe_neurosim_crash_boundary.py`)을 실행했습니다. V1.4를 유지했고 MNIST 모델은
바꾸지 않았습니다.

**기록돼 있던 규칙 두 개가 직접 측정으로 반증됐습니다.**
1. "출력 96 미만은 모두 crash" → 틀림. `128×10`, `256×10`, `1024×10`, `256×64` 모두 완주.
   기존 `MIN_SAFE_OUT_FEATURES=96` 가드가 **실제로 도는 형상을 거부**하고 있었습니다.
2. "mnist_mlp_v1은 평가 불가" → 틀림. **subArray 256에서 완주**합니다. 이전 스윕이 이 형상에
   64/128만 시도했습니다. 재빌드가 아니라 **배열 크기가 결정 요인**입니다(스톡 바이너리도 256에서 완주).

crash는 fan_in에 단조롭지 않습니다(257·260·320 crash, 512 완주, 784 crash). 일반 규칙을
주장하지 않고 측정된 `(형상, subArray)` 쌍만 `MEASURED_TOPOLOGIES`에 기록했으며,
`topology_support(layer_dims, sub_array)`는 측정에서 죽은 쌍만 거부합니다.
preset의 `sub_array`가 요청 배열과 다르면 차단합니다(다른 회로의 비용이 되므로).

### C3 AIHWKit — 완료
Linux Python 3.11 / torch 2.12.0 / AIHWKit 1.1.0 환경을 고정하고 parity probe로 게이팅합니다.
worker capability 기준으로만 노출하며 메인 workspace lock은 건드리지 않았습니다.
검증 스크립트를 v1.2 경로(bit-serial + 두 plane + 두 순서)로 교체했습니다.

## D. 데이터

### D1 원본 데이터 — 부분 구현
알려진 형식 기준으로 파이프라인을 유지했고, **A1 인수 조건을 행 번호 검증으로 교체**했습니다
(전환 행 j → 읽기 행 j-2, 명세 예시 1024→1022). 개수(1024/1022)는 파일별 provenance이므로
환경변수로 지정했을 때만 단언합니다. 원본 파일 도착 후 실행만 남았습니다.

작업 중 기존 A1 테스트의 결함 두 개를 고쳤습니다: `source_rows` 미전달, 열 매핑 키 오타
(`columns=`). 실제 파일이 와도 그대로는 실행되지 않는 상태였습니다.

### D2 C2C — 미구현
형식 미정. 계약상 `c2c: false` 고정, UI disabled 유지. 사유는 별도 문서 참조.
