## 5. 예제 실행의 증거와 읽는 법 (실행 조건이 다른 결과를 섞지 않기)

`simulator-guide.md` 5장의 4개 실행은 **같은 저장소(`serve`), 같은 프로필 A2, ADC 5 bit, 같은 모델 가중치(`torch.equal`로 확인)** 에서 얻은 것입니다.

| 실행 | 평균 | 각 반복 |
|---|---:|---|
| C2C OFF | 95.64 % | 95.64 |
| C2C 전체 변동 6.0755 % | 95.63 % | 95.57, 95.71, 95.47, 95.77, 95.61 |
| C2C 추세 제거 후 2.9179 % | 95.78 % | 95.80, 95.84, 95.67, 95.73, 95.84 |
| D2D 47.3534 % (배열 3) | 86.31 % | 87.71, 86.49, 84.74 |

- 전체 변동(95.63)과 추세 제거 후(95.78)의 차이는 0.15 %p이고 반복별 표본 표준편차는 0.12·0.07 %p입니다. 반복이 5회뿐이라 **우열을 단정하지 않습니다.** 기준(OFF 95.64)보다 추세 제거 실행이 높게 나온 것도 "C2C가 정확도를 높인다"는 뜻이 아닙니다.
- **참고(다른 저장소의 별도 실행, 위 표와 섞지 않음)**: 코드 검증 단계에서 다른 데이터 폴더에 같은 파일을 새로 올려 같은 조건으로 돌렸을 때는 OFF 95.64, 전체 변동 95.65, 추세 제거 95.68, D2D(배열 3) 84.98 %가 나왔습니다. 새 프로필을 만들면 난수가 달라져, 같은 조건의 C2C 실행 평균이 0.02~0.10 %p, D2D(배열 3 평균)가 약 1.3 %p 달라졌습니다. 즉 **두 실행 사이의 이만큼의 차이는 난수 차이이지 조건의 효과가 아닙니다.** 이 "참고"의 값은 안내서의 예제 결과로 쓰지 마세요.
- 같은 파일로 같은 설정을 **복제해** 다시 돌린 실행은 같은 평균(95.63 %)이 나왔습니다(개별 반복 값은 폐기된 임시 결과라 대조하지 않음).

## 8. 연구·측정 조건 확인이 필요한 항목 (⚖)

1. **C2C 대표 스윕 구간**(초기/상승/하강): 소자팀 확인 전. 안내서 예제의 6.0755 %, 2.9179 %는 *상승 중 0 V를 예로 고른 값*입니다.
2. **측정 VDS가 0.1 V였는지**와 기록 절차: C2C 파일은 알려 주지 않음(전류 CV = 전도도 CV는 VDS가 사이클마다 같은 양수일 때만).
3. **D2D 파일 번호 ↔ 물리 소자 대응**: 파일 번호를 소자 번호로 해석하지 않음. 두 소자만으로 구한 대표값이고 로그정규·"모든 상태에 같은 편차"는 가정.
4. **A4·A5의 특이값**(A4 하강 3.5×10⁻¹³ A, A5 상승 사이클 11의 1.848 µA)이 측정 이상인지 실제 현상인지: 이 자료는 판단하지 않고 그대로 포함해 계산.
5. A3 하강(35.1 % → 추세 제거 16.5 %)처럼 **추세가 큰 데이터**에서 어느 값을 대표로 쓸지.
6. I–V의 **program 후보 두 가지**(처음 0→−A 반쪽 `구간 0` vs +A→−A 전체 `구간 2`) 중 연구에 맞는 쪽.
7. Retention 10년 외삽은 로그-선형 모델의 연장이며 수명 보증이 아님.
